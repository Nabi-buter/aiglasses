1학습 사진 넣기

수집한 ZIP 파일이나 data 폴더를 여기에 끌어다 놓으세요.

폴더 이름으로 정답을 구분합니다: ai_glasses/ · regular_glasses/ · no_glasses/. 실시간 판독 화면의 ‘학습 데이터 수집’ ZIP이 그대로 맞습니다. 여러 번에 걸쳐 모은 ZIP을 한꺼번에 넣어도 됩니다.

2학습

기본 공개 데이터는 앱에 들어 있는 공개 사진(Open Images, Wikimedia Commons)의 특징값입니다(사진은 없음). 직접 모은 사진과 합쳐 학습하므로 사진이 적어도 세 가지 판정이 모두 나오고, 모을수록 직접 찍은 조건에 맞게 좋아집니다.

사진마다 얼굴을 찾아 안경 영역 특징을 뽑은 뒤(사진 1장에 0.1~0.5초), 사람 단위로 나눈 교차검증으로 성능을 재고 최종 모델을 만듭니다. 한 번 처리한 사진은 이 브라우저에 특징값이 저장되어, 다음 학습 때는 새 사진만 처리합니다. 노트북·데스크톱 사용을 권장합니다.

4모델 적용 · 배포

‘이 기기에서 바로 사용’은 이 브라우저에만 적용됩니다. 다른 기기·다른 감독관과 함께 쓰려면 아래 5. 공용 모델에 기여로 올리세요. 모든 기여가 합쳐져 공용 모델이 계속 커집니다.

공용 모델이 이 기기 모델보다 새로 만들어지면 판독 화면은 자동으로 공용 모델을 씁니다(이 기기 모델은 ‘판독 모델’ 칸에서 다시 고를 수 있습니다). head.json 내려받기는 백업이나 다른 브라우저로 옮길 때 쓰세요.

5공용 모델에 기여 (모든 기기·사용자와 함께 키우기)

여기서 학습한 모델은 이 기기의 이 브라우저에만 적용됩니다. 여러 감독관이 모은 사진을 합쳐 공용 모델을 키우려면, 넣은 사진의 특징값을 기여 파일로 만들어 저장소에 올리세요.

  1. 기여 파일 만들기 — 사진은 들어가지 않고, 앱이 계산한 숫자(특징값)·정답·기종·익명화된 사람 묶음만 들어갑니다.
  2. GitHub에 올리기를 눌러 열린 페이지에 파일을 끌어다 놓고 Commit changes (저장소 관리자가 아니면 자동으로 ‘변경 제안(Pull request)’이 되어 관리자가 확인 후 합칩니다).
  3. 합쳐지면 서버(GitHub Actions)가 공개 데이터 + 지금까지의 모든 기여로 다시 학습하고, 품질 기준을 통과하면 공용 모델을 자동으로 바꿔 배포합니다. 모든 기기는 새로 고치면 새 모델을 씁니다.
