1학습 사진 넣기

수집한 ZIP 파일이나 data 폴더를 여기에 끌어다 놓으세요.

폴더 이름으로 정답을 구분합니다: ai_glasses/ · regular_glasses/ · no_glasses/. 실시간 판독 화면의 ‘학습 데이터 수집’ ZIP이 그대로 맞습니다. 여러 번에 걸쳐 모은 ZIP을 한꺼번에 넣어도 됩니다.

2학습

사진마다 얼굴을 찾아 안경 영역 특징을 뽑은 뒤(사진 1장에 0.1~0.5초), 사람 단위로 나눈 교차검증으로 성능을 재고 최종 모델을 만듭니다. 한 번 처리한 사진은 이 브라우저에 특징값이 저장되어, 다음 학습 때는 새 사진만 처리합니다. 노트북·데스크톱 사용을 권장합니다.

4모델 적용 · 배포

모든 감독관 기기에 배포하려면 내려받은 head.json을 저장소에 올리세요. 1~2분 뒤 웹 주소에 자동으로 반영됩니다.

  1. GitHub 저장소에서 web/models 폴더를 엽니다.
  2. Add file → Upload files로 head.json을 올리고 Commit changes를 누릅니다 (브랜치는 기본값 그대로).
  3. 감독관은 웹 주소를 새로 고치기만 하면 새 모델을 씁니다. 판독 화면의 ‘판독 모델’ 칸에서 학습 시각으로 확인할 수 있습니다.

head.json에는 숫자(가중치)와 성능 수치만 들어 있고 사진은 들어 있지 않습니다. 사진은 저장소에 올리지 마세요.
