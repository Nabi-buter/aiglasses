# 공용 모델 기여 파일

이 폴더의 `*.json` 파일이 **공용 모델**에 합쳐집니다.

- **만드는 곳:** 웹 앱의 **모델 학습 → 5. 공용 모델에 기여**
- **들어 있는 것:** 사진이 아니라 앱이 계산한 특징값(숫자), 정답, AI 안경 기종, 익명화된 사람 묶음, 메모
- **올리는 방법:** 학습 페이지의 **바로 적용**(토큰 등록 후 버튼 하나), 또는 GitHub에서 이 폴더 → **Add file → Upload files** → 파일을 끌어다 놓고 **Commit changes**
  - 저장소 관리자가 아니면 자동으로 변경 제안(Pull request)이 되고, 관리자가 확인한 뒤 합칩니다.
- **합쳐진 뒤:** main에 들어오면 배포 워크플로가 **공개 기본 데이터와 지금까지의 모든 기여**를 합쳐 다시 학습합니다.
  - 품질 기준을 통과하면 새 공용 모델을 배포하고, 모든 기기는 새로 고치면 새 모델을 씁니다.
  - 통과하지 못하면 배포가 멈추고 사이트는 이전 모델을 그대로 씁니다. 이유는 Actions 실행 요약에 나옵니다.
- **빼려면:** 잘못 올린 파일은 지우면 다음 배포 때 빠집니다.

자세한 내용은 [docs/CONTRIBUTING.md](../docs/CONTRIBUTING.md)를 보세요.
