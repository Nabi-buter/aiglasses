# 학습 데이터 수집 가이드

판독 성능은 거의 전부 **데이터**에서 나옵니다. 코드는 바꾸지 않아도 사진을 잘 모으면 좋아집니다.

## 폴더와 파일 이름

```
data/
  ai_glasses/         AI 안경을 쓴 사람
  regular_glasses/    일반 안경을 쓴 사람 (선글라스 포함)
  no_glasses/         안경을 쓰지 않은 사람
data_test/            같은 구조. 학습에 쓰지 않는 평가용 (다른 날, 다른 사람)
```

**같은 사람이나 같은 촬영 세션의 사진에는 같은 접두어를 붙이세요.**

```
ai_glasses/p07__front.jpg
ai_glasses/p07__left45.jpg
ai_glasses/p07__side.jpg
```

`__` 앞부분(`p07`)이 같은 사진은 교차검증에서 한 묶음으로 처리됩니다.
이렇게 하지 않으면 같은 사람의 사진이 학습과 검증에 나뉘어 들어가 정확도가 실제보다 높게 나옵니다.

학습할 때 `--test data_test`를 주면, 학습에 쓰지 않은 사진으로 따로 평가한 결과가 출력됩니다.
결과는 `head.json`에도 기록됩니다.

## 얼마나

| 단계 | 클래스당 사진 | 사람/세션 수 | 용도 |
| --- | --- | --- | --- |
| 시험해 보기 | 50 | 10 이상 | 동작 확인 |
| 내부 시범 운영 | 200 | 30 이상 | 감독관 보조로 시범 사용 |
| 실전 | 500+ | 80 이상 | 여러 고사장 운영 |

## AI 안경 (`ai_glasses`)

- **기종을 고르게** 모읍니다.
  - 카메라형: Ray-Ban Meta(Wayfarer·Skyler·Headliner), Oakley Meta, Xiaomi, Alibaba Quark, Rokid 등
  - 디스플레이형: Meta Ray-Ban Display, Even Realities, RayNeo, XREAL 등
  - 오디오형: Echo Frames, Bose, Solos 등

  실제 응시자가 쓸 법한 기종을 먼저 모으세요.
- **실제 감독 상황처럼** 찍습니다.
  - 1~3m 거리에서 정면, 45°, 측면
  - 형광등 조명, 감독관 휴대폰 카메라, 디지털 확대
  - 앉은 자세에서 고개를 숙인 각도
- **조건을 다양하게** 합니다. LED가 켜진 사진과 꺼진 사진, 머리카락이 다리를 가린 사진, 안경을 콧등 아래로 내려 쓴 사진을 섞으세요.
- **사람을 다양하게** 합니다. 나이, 성별, 피부색, 머리 모양이 다른 사람들을 찍으세요.

## 일반 안경 (`regular_glasses`). 오판을 줄이는 핵심

모델이 "두꺼운 테 = AI 안경"으로 잘못 배우지 않도록, **AI 안경과 닮은 일반 안경**을 꼭 넣으세요.

- **일반 Ray-Ban Wayfarer, Oakley 등.** Ray-Ban Meta와 디자인이 같은 일반 제품이 가장 중요한 사진입니다.
- **두꺼운 뿔테, 각진 다리, 장식 리벳이나 금속 장식이 있는 테.** 리벳이 카메라 렌즈처럼 보일 수 있습니다.
- **스포츠 고글형, 변색 렌즈, 블루라이트 차단 렌즈.** 렌즈 반사가 디스플레이처럼 보일 수 있습니다.
- 반무테, 무테, 금속테 같은 흔한 안경도 충분히 넣으세요.

## 안경 없음 (`no_glasses`)

선택이지만 넣는 것을 권합니다. 안경을 안 쓴 사람에게 엉뚱한 판정이 나오는 것을 막습니다.

## 출처와 권리

- **가장 좋은 출처는 직접, 동의를 받고 찍은 사진**입니다.
  - 기기를 빌리거나 매장 체험대를 이용하세요.
  - 모의 고사실에서 동료나 자원자에게 동의를 받고 찍으세요.
- **인터넷 이미지**(제품 사진, 리뷰 영상 캡처 등)는 저작권과 각 사이트 약관을 직접 확인한 뒤 판단하세요.
  - 써도 되는 경우라도 내부 학습에만 쓰고 저장소에 올리지 마세요.
  - 제품 단독 사진(사람이 없는 사진)은 얼굴을 찾지 못해 학습에서 자동으로 빠집니다.
- **공개 얼굴 데이터셋**은 일반 안경과 안경 없음 클래스에 쓸 수 있습니다. 예를 들어 CelebA의 Eyeglasses 속성이 있습니다.
  - 대부분 비상업·연구용 라이선스입니다. 쓰려는 용도에 맞는지 확인하세요.
- `data/`는 `.gitignore`에 들어 있습니다. **사람 얼굴 사진을 공개 저장소에 올리지 마세요.**
  - 공개해도 되는 것은 학습 결과인 `head.json` 뿐입니다. 숫자만 들어 있습니다.

## 점검 순서

1. 잘라낸 영역을 눈으로 확인합니다.

   ```bash
   python training/predict.py data/ai_glasses/*.jpg --save-crops /tmp/crops
   ```

   경첩 영역에 카메라가 들어오는지 봅니다.
2. 학습합니다.

   ```bash
   python training/train.py --data data --test data_test --out web/models/head.json
   ```

3. 혼동행렬에서 **AI 안경을 일반 안경으로 놓친 칸**을 봅니다.
   - `--json` 출력으로 놓친 사진을 찾으세요.
   - 그런 사진과 비슷한 조건의 사진을 더 모읍니다.
4. 새 기종이 나오면 그 기종 사진을 추가하고 다시 학습합니다. 특징 캐시 덕분에 새 사진만 처리합니다.
